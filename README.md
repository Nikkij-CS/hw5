# Question 3: Basic GAN Implementation on MNIST Dataset

## Objective
To implement and train a simple Generative Adversarial Network (GAN) from scratch to generate handwritten digit images similar to the MNIST dataset.

## Dataset
- MNIST handwritten digits dataset.
- Each image is 28x28 pixels, grayscale.

## Steps Performed

### 1. Set Up Environment
- Import necessary libraries: PyTorch, torchvision, matplotlib.
- Configure device to use GPU if available, otherwise CPU.

### 2. Define the Generator
- A neural network that takes a random noise vector (size 100) and outputs a 28x28 fake image.
- Architecture:
  - Fully connected layers with ReLU activations.
  - Final output layer uses `Tanh` activation to scale outputs between -1 and 1.

### 3. Define the Discriminator
- A neural network that takes an image (real or fake) and outputs a probability (real or fake).
- Architecture:
  - Fully connected layers with LeakyReLU activations.
  - Final output layer uses `Sigmoid` activation.

### 4. Prepare the Data
- Download and preprocess the MNIST dataset using `torchvision.datasets`.
- Normalize images to [-1, 1] range.
- Load data in batches using `DataLoader`.

### 5. Set Up Training Components
- Define Binary Cross Entropy Loss (`BCELoss`) for both generator and discriminator.
- Use Adam optimizer for both models.
- Set hyperparameters: learning rate, batch size, number of epochs.

### 6. Training Loop
- For each epoch:
  - **Train Discriminator:**
    - On real images labeled as real (1).
    - On fake images generated by the generator labeled as fake (0).
  - **Train Generator:**
    - Generate fake images and try to fool the discriminator (label fake images as real).
  - Log generator and discriminator losses.
- Save and display generated images at Epoch 0, 50, and 100.

### 7. Visualization
- Save generated samples as PNG images.
- Plot generator and discriminator loss curves over training epochs.

## Output (Expected)
- **Generated Images:** At Epochs 0, 50, and 100.
- **Loss Curves:** Showing how the generator and discriminator improve over time.
- **Model Behavior:** Gradually improving fake digit quality over epochs.


# Question 4: Data Poisoning Simulation on Sentiment Classifier

## Objective
To simulate a data poisoning attack on a simple sentiment classifier by flipping labels related to a specific entity ("UC Berkeley") and observe the impact on model performance.

## Dataset
- A small synthetic dataset containing 12 text samples.
- Each sample is labeled as either **positive** (1) or **negative** (0).
- Some samples specifically mention **"UC Berkeley"**.

## Steps Performed

### 1. Create and Preprocess Dataset
- Manually create a dataset containing positive and negative sentences.
- Include several sentences mentioning "UC Berkeley".

### 2. Train-Test Split
- Split the dataset into **training** (70%) and **testing** (30%) sets using `train_test_split`.

### 3. Vectorize the Text
- Use `CountVectorizer` to convert text sentences into numerical feature vectors suitable for model training.

### 4. Train Baseline Classifier
- Train a **Logistic Regression** classifier using the original (clean) training data.
- Predict on the test data and calculate:
  - **Accuracy before poisoning**
  - **Confusion matrix before poisoning**

### 5. Poison the Training Data
- Identify all training samples containing "UC Berkeley".
- Flip their sentiment labels (positive becomes negative and vice versa).
- This simulates a targeted data poisoning attack.

### 6. Retrain Classifier on Poisoned Data
- Retrain the Logistic Regression model on the poisoned training data.
- Predict again on the original test data.
- Calculate:
  - **Accuracy after poisoning**
  - **Confusion matrix after poisoning**

### 7. Visualization
- Create a **bar chart** comparing model accuracy **before** and **after** poisoning.
- Display **confusion matrices** side-by-side to visualize the degradation in classification performance.

### 8. Analyze Impact
- Print a summary showing the drop in accuracy.
- Highlight increased misclassifications, especially for sentences mentioning "UC Berkeley".

## Output (Expected)
- **Accuracy Comparison Graph:** Bar chart showing accuracy before and after poisoning.
- **Confusion Matrices:** Before and after poisoning.
- **Impact Explanation:** Text output indicating how poisoning affected classification performance.
